# Pangamoja Backend

Backend service for the Pangamoja platform.

## Overview
Pangamoja is a tenant-aware, rule-based platform designed for managing structures and operations across multiple business entities.

This repository contains the backend service responsible for:
- Tenant isolation
- Core domain logic
- Structure management APIs

## Tech Stack
- Java 17
- Spring Boot
- H2 (MVP / development)
- Maven

## Status
🚧 MVP0 – foundational backend setup (tenant filter, structure API, in-memory DB)

## Notes
This project is under active development and not yet production-ready.
